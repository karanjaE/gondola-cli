## [0.1.0] - 2025-02-14

### Added

- Initial release
- Project scaffolding with `gondola create project`
- Model generator with SQLModel and UUID7 support
- Router generator with RESTful endpoints
- Service generator with Celery integration
- Mailer generator with SMTP support
- Migration commands (create, upgrade, downgrade, history, current)
- Delete commands for models and routers
- Server commands for running FastAPI and Celery
- Docker and docker-compose support
- PostgreSQL and SQLite database support
- Comprehensive test generation
- Type safety with mypy
